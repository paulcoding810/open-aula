      Making a small GIF with ffmpeg

      Every frame costs ~63 KB on the keyboard no matter how small the GIF file is, so keep the frame count low: 8–12 fps for 2–4 seconds works well (30 frames ≈ 1.9 MB). Install with brew install ffmpeg.

      From a video, 3 seconds at 10 fps, cropped to fill the screen:

      ffmpeg -i input.mp4 -t 3 -vf "fps=10,scale=135:240:force_original_aspect_ratio=increase,crop=135:240" out.gif

      Thin out an existing GIF to 8 fps:

      ffmpeg -i input.gif -vf "fps=8,scale=135:240:force_original_aspect_ratio=increase,crop=135:240" out.gif

      Better colours (two-pass palette):

      ffmpeg -i input.mp4 -t 3 -vf "fps=10,scale=135:240:force_original_aspect_ratio=increase,crop=135:240,split[a][b];[a]palettegen[p];[b][p]paletteuse" out.gif
